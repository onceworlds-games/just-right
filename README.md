# Just Right

Twelve storybook pages, one button. Hold, then let go in the green: porridge not too hot, a chair not too high, toast
not burnt. Up to eight players share each page and see everyone's release at once. Before the three bears come home.

Play: https://onceworlds.com/play/just-right

Tests: `npm test` (Node 22 or later, nothing to install).

MIT licensed.
