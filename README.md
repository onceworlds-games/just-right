# Just Right

One button, twelve pages of the story: hold, let go in the green. Porridge not too hot, Baby Bear's chair not too low, the
pillow just fluffed, a rope swing onto the raft. A 3D storybook cottage for up to eight players, with Before the Bears (a run
with charms, a boss and three bears for lives), a daily, ranks and a wardrobe.

Play: https://onceworlds.com/play/just-right

Run the tests: `npm install`, then `npm test` (Node 22 or later). Build: `npm run build` (into `dist/`).
